# 2048

Game 2048 chạy trực tiếp trên trình duyệt, không cần cài đặt hay build.

## Chạy trên máy

Mở `index.html` bằng trình duyệt.

## Đưa game lên GitHub Pages

1. Tạo repository GitHub và tải các tệp trong thư mục này lên nhánh `main`.
2. Mở **Settings → Pages** trong repository.
3. Trong **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn nhánh `main`, thư mục `/(root)`, rồi nhấn **Save**.
5. Sau khi GitHub Pages triển khai xong, mở đường dẫn được hiển thị trong mục Pages.

Dùng các phím mũi tên hoặc WASD trên máy tính; vuốt trên bàn chơi khi dùng điện thoại. Điểm cao được lưu trên trình duyệt hiện tại.
